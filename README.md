# EZ 학생 시험판 다운로드

## 설치 방법

1. [최신 버전 다운로드](https://github.com/parkjikoon-hub/ez-download/releases/latest)에서 `ez-0.6.21-student-preview-win-x64.zip`을 받습니다.
2. ZIP을 모두 풀고 `ez 사용 설명서.html`을 먼저 읽습니다.
3. 풀어 놓은 폴더의 `ez.exe`를 실행합니다. Windows 10/11 64비트용이며 .NET을 별도로 설치할 필요가 없습니다.

## 영역 캡처는 두 동작

캡처 도구 열기 → 영역 선택 → 드래그 → 복사 → 붙여넣기 또는 저장 순서로 작업하는 경우가 있습니다. EZ에서는 **① Ctrl을 누른 채 오른쪽 드래그 → ② 원하는 곳에 붙여넣기**로 끝납니다. 설정에서 **Z + 왼쪽 드래그**로 바꿀 수도 있습니다. 마우스를 놓는 순간 그림이 이미 복사되고, 사진 폴더의 ez 폴더에도 자동 저장됩니다. 별도 복사·저장 단추를 누르지 않아도 됩니다.

이 단계 비교는 일반적인 작업 흐름의 예이며, 모든 캡처 프로그램이 같은 단계를 거친다는 뜻은 아닙니다.

## 필요한 장면에 맞는 찍기 방법

- **긴 페이지:** 영역을 찍은 뒤 휠로 내려 한 장으로 이어 붙입니다. 시험 기능이므로 결과의 빠진 줄·겹친 줄을 확인해 주세요.
- **직전 영역 다시 찍기:** 한 창 안쪽 영역을 찍어 두면 나중에 그 자리를 다시 촬영할 수 있습니다. 다른 창으로 원래 창을 가려도 원래 창의 새 화면을 읽습니다. 원래 창이 닫히거나 크기가 바뀌면 다시 찍지 못할 수 있습니다.
- **마우스 아래 창 한 번에:** Ctrl을 누른 채 오른쪽 버튼으로 클릭만 하면 마우스 아래 창 전체를 찍습니다.
- **글자만 복사:** 캡처 그림에서 필요한 문구만 추출해 붙여넣을 수 있습니다.
- **Z 설정:** Z를 짧게 누르면 영문 z 또는 한글 ㅋ을 입력하고, 누른 채 왼쪽 드래그하면 캡처합니다.

## 개발 중인 기능

**긴 화면 자동 찍기**는 아직 완성되지 않았습니다. 자동으로 마지막까지 찍혔다고 가정하지 말고 결과를 확인해 주세요. 계획된 나머지 기능은 HTML 설명서 마지막의 개발 예정 목록에 적었습니다.

## 의견 보내기

ZIP 안의 `시험 사용 의견.txt`에 오류와 개선 의견을 적어 배포자에게 전달해 주세요. 회사 자료나 개인정보가 보이는 화면은 가리고 공유해 주세요.

실행 파일은 코드 서명이 없는 시험판입니다.
